# 使用指南

> 一句话：装好官方微信 → 装本工具 → 加一个实例 → 扫码登录 → 以后点图标就行。

---

## 一、准备

### 1. 装官方微信

装 [微信 PC 版](https://windows.weixin.qq.com/)，版本 4.x（4.1.15 及以后）。
装完确认主号能正常登录。

### 2. 装本工具

解压 `WeChatMulti-v*-win64.zip` 到一个位置，然后：

- **推荐**：双击 `微信多开安装器.exe` → 选安装目录 → 完成
- **或者**：直接双击 `微信多开管家.exe`，首次运行会引导你完成安装

### 选目录的规矩

| 要求 | 原因 |
|---|---|
| 本地磁盘 | 微信要持续读写，网络盘会卡 |
| **不要** OneDrive / 任何同步盘 | 同步盘会把聊天记录同步来同步去，还会锁文件 |
| **不要** U 盘 / 移动硬盘 | 拔掉就没了，微信也会崩 |
| 留出 **2 GB 以上**空间 | 每个实例约 870 MB 程序文件，聊天记录另算 |

安装器会直接告诉你这个目录合不合适。

---

## 二、加第一个实例

打开「微信多开管家」→ 点 **「新增实例」**。

安装器会自动完成这几件事：

1. 在电脑上找已安装的官方微信（读注册表 + 常见目录）
2. 把程序文件复制一份到 `<安装目录>\<代号>\`
3. 建好独立的 `Profile`（配置目录）
4. 把聊天数据根预置到 `<安装目录>\Data\<代号>\`
5. 在桌面建一个启动图标

代号自动分配：A、B、C…

### 首次启动要扫码

双击新图标 → 微信会弹出登录二维码 → **用手机微信扫一下**。

> 每个实例只能登录一个号。想换号就删掉实例重新加。

## 三、日常使用

| 想做什么 | 怎么做 |
|---|---|
| 启动某个号 | 双击桌面上的 `微信X` 图标 |
| 看所有实例 | 打开「微信多开管家」 |
| 区分窗口 | 标题自动是 `微信A` / `微信B`，任务栏上一眼分清 |
| 备份某个号的聊天记录 | 复制 `<安装目录>\Data\<代号>\` 整个目录 |
| 换个号 | 管家 → 选中实例 → 删除 → 重新新增 |

---

## 四、常见场景

### 场景 1：三个号一起挂着

装三个实例，各扫各的码。之后开机后点三个图标就行，
它们会同时在线、同时收消息。

### 场景 2：给同事/家人用

把整个安装目录连同 `Data\` 一起拷过去就行。
但**微信程序文件不用拷** —— 新电脑上装一次官方微信，
然后用本工具的安装器指向它，会自动复制一份。

### 场景 3：备份与迁移

每个实例的聊天记录都在 `<安装目录>\Data\<代号>\`，
**和程序文件是分开的**。备份这个目录就够了。

恢复时：新电脑上装好本工具 → 新增实例 → 手动把数据根指到拷回来的目录。

## 五、遇到问题

看 [常见问题.md](常见问题.md)。

最常见的三件事：

1. **双击图标没反应** → 检查管家里的状态；可能已经在跑了（防重复启动挡住了）
2. **扫码后提示「已在其它设备登录」** → 微信自己的策略，同一个号不能同时登两台电脑
3. **实例卡在旧版本** → 微信自动更新只作用于主实例，多开实例的版本要手动同步

---

## 六、卸载

1. 管家 → 逐个删除实例（**删除实例不会删聊天记录**，除非你显式勾选）
2. 手动删除安装目录
3. 删除桌面上的图标
4. 主账号不受影响，继续用官方微信即可

---

## 七、安全与合规

- 本工具**完全使用原版微信客户端**，不改一个字节
- **官方本身就允许多开**，同机多账号是个人正常使用
- 工具只做**资料隔离**，让你不必反复扫码
- **无毒无害**：不装驱动、不装服务、不联网、不写注册表
- **合法合规**：所有操作都在你自己的电脑上，用你自己的账号
- **持续跟随官方版本更新**：工具不含微信文件，官方更新后照常可用

详见 [README](../README.md#合规声明)。
